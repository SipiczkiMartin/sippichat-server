Next step: JWT middleware

Now we make the token useful.

Currently the token is just being created. The server cannot yet say:

"This request belongs to user X."

We'll add:

internal/auth/
    jwt.go
    middleware.go

The middleware will:

Read:
Authorization: Bearer <token>
Validate:
signature
expiry
claims
Put the user ID into the request context.

Then handlers can do:

userID := auth.UserIDFromContext(r.Context())

After middleware, we'll create:

GET /me

Flow:

curl
 |
 | Authorization: Bearer eyJ...
 |
 v
JWT Middleware
 |
 v
/me Handler
 |
 v
Database lookup
 |
 v
{
  "id": "...",
  "email": "test@test.com"
}

That endpoint will be the first real proof that your authentication architecture works.

Before we write middleware, I want to make one small improvement to jwt.go: add a ParseAccessToken() function next to GenerateAccessToken(). Then the middleware will have a clean API instead of knowing JWT internals.
